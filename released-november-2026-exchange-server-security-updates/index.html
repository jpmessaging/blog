2026 年 11 月の Exchange Server セキュリティ更新プログラムが公開されました

Last Update: 2026-11-11

※ この記事は、Released: November 2026 Exchange Server Security Updates の抄訳です。最新の情報はリンク先をご確認ください。この記事は Microsoft Copilot および GitHub Copilot を使用して抄訳版の作成が行われています。

Microsoft は、以下の製品で見つかった脆弱性に対応するセキュリティ更新プログラム (SU) をリリースしました。

  • Exchange Server Subscription Edition (SE)

以下の Exchange Server のバージョン向けに SU が提供されています。

  • Exchange SE RTM

2026 年 11 月の SU は、セキュリティ パートナーから責任を持って報告された脆弱性や、Microsoft の内部プロセスで発見された脆弱性に対応しています。

これらの脆弱性は Exchange Server に影響します。Exchange Online のお客様は、今回の SU で対応された脆弱性から既に保護されているため、環境内の Exchange サーバーや Exchange 管理ツールをインストールしたワークステーションを更新する以外の対応は不要です。

特定の脆弱性 (CVE) の詳細は、Security Update Guide (Exchange SE については Product Family で “Server Software” を選択してフィルター) を参照してください。

Exchange Server 2016 および 2019 の情報をお探しですか？

Exchange Server 2016 および 2019 はサポートが終了しているため、脆弱性の検証は行われず、更新プログラムもリリースされません。これらのバージョンを使用している場合、恒久的に脆弱な状態にあるものとして、直ちに組織を Exchange Server Subscription Edition (SE) にアップグレードしてください。

解決された問題

  • 2026 年 10 月の Windows 更新プログラム適用後、Exchange サーバーが不安定になる可能性があります。任意のバージョンの Exchange が 2026 年 10 月の Windows Server 更新プログラムのインストール後に不安定になる可能性がある問題に対処するには、Windows Server の 2026 年 11 月の更新プログラムをインストールしてください。10 月の問題に対処するためにレジストリ キーを作成した場合、そのまま残しておいて問題ありませんが、11 月の Windows Server 更新プログラムをインストールすれば、このキーは不要です。2026 年 11 月の Exchange Server と Windows Server の更新プログラムをインストールする順序は問いません。

更新プログラムのインストール

利用可能な更新パスは以下のとおりです。

  • Exchange Server Health Checker スクリプトを使用して Exchange サーバーのインベントリを作成し、必要な更新プログラムを確認してください。このスクリプトを実行すると、CU、SU、手動対応の適用漏れがある Exchange サーバーを確認できます。
  • セットアップ完了後、サーバーを再起動し、すべての Exchange サービスが正常に起動したことを確認してください。一部のサービスが無効状態の場合は、更新プログラムのインストールが何らかの理由で中断されたことを示しています。詳細については、この記事の「回避策 1」を参照してください。
  • Exchange Server のインストール中やインストール後にエラーが発生した場合は、SetupAssist スクリプトを実行してください。更新後に正常に動作しない場合は、失敗した Exchange 累積更新プログラムおよびセキュリティ更新プログラムのインストールを修復する方法を参照してください。また、Exchange Server の更新プログラムをインストールしようとしたときに発生するファイル バージョン エラーも参照してください。

よくあるご質問

組織は Exchange Online とのハイブリッド モードです。何か対応が必要ですか？

Exchange Online は既に保護されていますが、管理目的のみで使用している場合も含め、Exchange サーバーにはこの SU をインストールする必要があります。SU のインストール後に認証証明書を変更した場合は、ハイブリッド構成ウィザードを再実行してください。

最後にインストールした SU/HU は数か月前のものです。最新の SU をインストールするために、すべての SU をインストールする必要がありますか？

SU は累積的です。SU でサポートされている CU を実行している場合、SU や HU を順番にすべてインストールする必要はありません。最新の SU をインストールしてください。詳細については、こちらのブログ記事を参照してください。

組織内のすべての Exchange Server に SU をインストールする必要がありますか？「Exchange 管理ツールのみ」がインストールされたマシンはどうなりますか？

管理ツール クライアントとサーバー間の互換性を確保するため、すべての Exchange Server、および Exchange 管理ツールを実行しているすべてのサーバーとワークステーションに SU をインストールすることを推奨します。稼働中の Exchange Server がない環境で Exchange 管理ツールのみを更新する場合は、こちらを参照してください。

Exchange SU または HU をインストール済みで、Windows Server 2025 を実行しています。Windows Server 2025 では更新プログラムが一覧に表示されません。どのようにアンインストールできますか？

セキュリティ更新プログラムのアンインストールは推奨しません。詳細については、Windows Server 2025 のコントロール パネルで Exchange のセキュリティ更新プログラムまたは修正プログラムを表示またはアンインストールできない場合を参照してください。

組織では引き続き Exchange Server 2016 または 2019 を使用しています。2026 年 10 月以降、これらのバージョンの更新プログラムや脆弱性に関する記載がありません。脆弱性はないということでしょうか？

Exchange Server 2016 および 2019 はサポートが終了しており、第 2 期 ESU プログラムも終了しました。このため、脆弱性の検証は行われず、更新プログラムもリリースされません。これらのバージョンを使用している場合、恒久的に脆弱な状態にあるものとして、直ちに組織を Exchange Server SE にアップグレードしてください。

本記事の公開時点では、関連ドキュメントが完全には公開されていない場合があります。
