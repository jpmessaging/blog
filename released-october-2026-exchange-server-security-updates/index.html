2026 年 10 月の Exchange Server のセキュリティ更新プログラムが公開されました

Last Update: 2026-10-16

※ この記事は、Released: October 2026 Exchange Server Security Updates の抄訳です。最新の情報はリンク先をご確認ください。この記事は Microsoft 365 Copilot および GitHub Copilot を使用して抄訳版の作成が行われています。

2026 年 10 月 16 日更新: 2026 年 10 月の Windows Server 更新プログラムのインストールおよび Exchange Server への影響の可能性に関する詳細については、2026 年 10 月の Windows 更新プログラム適用後、Exchange サーバーが不安定になる可能性があります をご参照ください。

Microsoft は、以下の製品に存在する脆弱性に対応するセキュリティ更新プログラム (SU) をリリースしました。

  • Exchange Server Subscription Edition (SE)
  • Exchange Server 2019
  • Exchange Server 2016

以下の Exchange Server のバージョン向けに SU が提供されています。

  • Exchange SE RTM
  • Exchange Server 2019 CU14 および CU15 (アクセスするには、第 2 期 ESU プログラムへの登録が必要)
  • Exchange Server 2016 CU23 (アクセスするには、第 2 期 ESU プログラムへの登録が必要)

2026 年 10 月の SU は、セキュリティ パートナーから責任を持って報告された脆弱性や、Microsoft の内部プロセスで発見された脆弱性に対応しています。

これらの脆弱性は Exchange Server に影響します。Exchange Online のお客様は、今回の SU で対応された脆弱性について既に保護されているため、特別な対応は不要です。ただし、環境内に存在する Exchange サーバーや Exchange 管理ツールをインストールしたワークステーションには、引き続き更新プログラムを適用してください。

特定の脆弱性 (CVE) の詳細は、Security Update Guide を参照してください。Exchange SE については Product Family で “Server Software” を選択し、Exchange Server 2016 および 2019 については Product Family で “ESU” を選択してフィルターしてください。

Exchange Server 2016 および 2019 向けの第 2 期 ESU プログラムが終了します

Exchange Server 2016 および 2019 はサポートが終了してから 1 年が経過しました。2026 年 10 月は、第 2 期 Extended Security Update (ESU) プログラムに登録しているお客様が、Exchange Server 2016 および 2019 向けの新しいセキュリティ更新プログラムを受け取れる最後の月です。

2026 年 10 月以降:

  • 更新プログラムは Exchange Server Subscription Edition (SE) 向けのみリリースされます。
  • 更新プログラムのお知らせや MSRC が公開する CVE で、Exchange Server 2016 および 2019 に言及されなくなります。これは、これらのバージョンが今後のセキュリティ上の問題の影響を受けないという意味ではありません。Exchange Server 2016 および 2019 の脆弱性のテストは終了します。
  • 第 2 期 ESU を購入できる期間はしばらく継続しますが、購入しても 2026 年 10 月のリリースまでのセキュリティ更新プログラムが適用された状態になります。

引き続き、組織の Exchange SE へのアップグレードを進めてください。

このリリースで解決された問題

  • 公開済みの予定表 (.ics) を予定表アプリケーションで開くと HTTP 500 エラーが返される | Microsoft Support
  • 韓国語の WordBreaker ルール ファイルが見つからず ContentEngine でデッドロックが発生する | Microsoft Support

更新プログラムのインストール

利用可能な更新パスは以下のとおりです。

  • Exchange Server Health Checker スクリプトを使用して、必要な更新プログラムを特定するために Exchange サーバーのインベントリを作成してください。このスクリプトを実行すると、Exchange サーバーに CU、SU、手動対応の適用漏れがないか確認できます。
  • 最新の CU をインストールします。Exchange Update Wizard で現在の CU と適用先の CU を選択し、手順を確認してください。
  • セットアップ完了後、サーバーを再起動し、すべての Exchange サービスが正常に起動したことを確認してください。一部のサービスが無効状態の場合は、更新プログラムのインストールが中断されたことを示しています。詳細については、この記事の「回避策 1」を参照してください。
  • Exchange Server のインストール中やインストール後にエラーが発生した場合は、SetupAssist スクリプトを実行してください。更新後に問題が発生した場合は、Exchange Server の累積更新プログラムとセキュリティ更新プログラムのインストール失敗を修復する方法や、Exchange Server の更新プログラムをインストールしようとしたときのファイル バージョン エラーも確認してください。

よくあるご質問

Exchange Online とのハイブリッド構成を使用しています。対応は必要ですか？

Exchange Online は既に保護されていますが、管理目的のみで使用している場合も含め、Exchange サーバーにはこの SU をインストールする必要があります。SU のインストール後に認証証明書を変更した場合は、ハイブリッド構成ウィザードを再実行してください。

最後にインストールした SU/HU は数か月前のものですが、最新の SU をインストールするためにすべての SU を適用する必要がありますか？

SU は累積的です。SU でサポートされている CU を使用している場合、SU や HU を順番にすべてインストールする必要はありません。最新の SU をインストールしてください。詳細はこちらのブログ記事を参照してください。

組織内のすべての Exchange Server に SU をインストールする必要がありますか。「管理ツールのみ」がインストールされたマシンはどうなりますか？

管理ツール クライアントとサーバーの互換性を確保するため、すべての Exchange Server、および Exchange 管理ツールを実行するすべてのサーバーとワークステーションに SU をインストールすることを推奨します。稼働中の Exchange サーバーがない環境で Exchange 管理ツールのみを更新する場合は、こちらを参照してください。

Exchange の SU または HU をインストール済みで、Windows Server 2025 を使用しています。更新プログラムが一覧に表示されない場合、どのようにアンインストールすればよいですか？

セキュリティ更新プログラムのアンインストールは推奨しません。詳細は、Windows Server 2025 のコントロール パネルで Exchange のセキュリティ更新プログラムまたは修正プログラムを表示またはアンインストールできない場合を参照してください。

Exchange Server 2016 および 2019 の第 2 期 ESU に登録していません。最新の Exchange Server 2016 または 2019 の更新プログラムを入手するにはどうすればよいですか？

Exchange Server 2016 および 2019 はサポートが終了しているため、第 2 期 ESU プログラム (2026 年 5 月から 10 月まで有効) に登録しているお客様のみが、2026 年 5 月以降にリリースされた Exchange Server 2016 または 2019 の更新プログラムを入手できます。Exchange Server 2016 または 2019 を引き続き使用している場合は、できるだけ早く組織を Exchange SE にアップグレードすることを推奨します。

本記事の公開時点では、関連ドキュメントが完全には公開されていない場合があります。
