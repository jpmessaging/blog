※ この記事は、[No Exchange Server Security Updates for May 2026](https://techcommunity.microsoft.com/blog/exchange/no-exchange-server-security-updates-for-may-2026/4519008) の抄訳です。最新の情報はリンク先をご確認ください。この記事は Microsoft 365 Copilot および GitHub Copilot を使用して抄訳版の作成が行われています。

Exchange Server コミュニティの皆さまにお知らせします。2026 年 5 月は、Exchange Server Subscription Edition (SE) をご利用の場合も、Exchange Server 2016 / 2019 の ESU をご利用の場合も、いずれのバージョンの Exchange Server に対してもセキュリティ更新プログラムのリリースはありません。

引き続き Exchange SE への移行を進めてください。

2026 年 5 月 14 日更新: 2026 年 5 月にセキュリティ リリース (セキュリティ更新プログラム) はありませんが、5 月 14 日に公開された Exchange Server の CVE に対する緩和策を紹介した記事も公開しています。[Exchange Server の 2026 年 5 月の脆弱性 CVE-2026-42897 への対処](/blog/addressing-exchange-server-may-2026-vulnerability-cve-2026-42897/) をご確認ください。
